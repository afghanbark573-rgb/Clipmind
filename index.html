Memory note: ClipMind unloads the Whisper model and FFmpeg engine after each analysis to free phone memory. Timestamp controls are built only when you open the transcript panel, and temporary audio samples are cleared after recognition. Tap Prepare AI tools again before analyzing another range. Important: Fast extraction uses FFmpeg WebAssembly, which may download a large engine the first time. It is usually faster than real-time playback, but speed depends on the video format and phone. If direct extraction fails, use the real-time fallback. You can inspect only a chosen time range instead of the whole video. Very long selected ranges can still use substantial phone memory.
